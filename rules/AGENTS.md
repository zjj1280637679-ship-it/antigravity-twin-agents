# 认知与叙事分身插件规范与约束

当本插件启用时，以下规则常驻生效：

1. **显式现场注入原则（Explicit Context Injection）**：
   * 因 Antigravity 子代理（`invoke_subagent`）启动时为独立全新会话，不自动继承父对话消息流：
     * **叙事推演模式**：主会话派发分支任务时，**必须将当前支线的前序因果链（Ancestral Story Chain）作为显式前缀注入 Prompt 开头**。
     * **认知复盘模式**：主会话必须显式注入**用户根本诉求与边界目标 $G$**，工作区文件作为客观事实证据 $C$，严禁依赖“子代理能心电感应父会话历史”的虚假假设。

2. **祖先亲和度分组与 Prefix Caching 准则**：
   * Google Gemini 隐式前缀缓存具有最低输入阈值（Gemini 3.8 Flash 为 4,096 Tokens）。
   * 调度器必须采用**祖先亲和度排序（Ancestor Affinity Grouping）**：同一批激活的分身（≤ 6 个），优先安排给共享相同长祖先链的任务节点，以最大化公共前缀重合度并越过 4k Tokens 门槛触发物理缓存命中。

3. **工作区隔离与防写竞争原则**：
   * 凡是需要分身执行代码修复、文件写入的任务，`Workspace` 参数**优先设为 `"branch"`**（独立隔离分支），或 `"share"`（共享工作树），防止主子代理并发写入导致脏工作区或文件冲突。
   * 纯分析、排查、叙事推演类任务使用 `"inherit"`。

4. **主控独占调度与并发池节流准则（参考 Claude Code 架构）**：
   * **全局独占权**：全局拓扑图、最大深度/章节上限（`max_depth`）以及子代理激活权**完全由主会话独占**。分身工具箱严禁配置 `invoke_subagent`，杜绝私自递归裂变。
   * **并发池节流（批次 ≤ 6 个）**：面对指数级分支（如 3 变 9、9 变 27）或大规模多任务协作时，主会话维护待激活队列（Task Queue），采用滑动窗口分组激活，**单批次并发严格控制在 ≤ 6 个智能体**，防止 API 限频、资源耗尽与智能体雪崩。

5. **分身局部单线与终局自决准则**：
   * **单线沉浸**：每个分身子代理只专注于自己的线性因果与连续体验，无需承担全局多分支调和压力。
   * **本步终结自决**：分身拥有对当前分支的本步自决权，自主评估当前步是“达成终局（Good End / Bad End / Normal End）”还是“产生分歧选项”。若产生新分支，仅向主会话提交候选选项，由主会话决定是否入队并在后续批次中激活。
